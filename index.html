Pavel rclone

Личное приложение Павла для работы со своим Google Диском через программу rclone.

Используется для просмотра, скачивания, загрузки и управления файлами владельца на его устройствах и сервере. Доступ предоставляется владельцем через авторизацию Google.

Приложение предназначено только для личного использования.
